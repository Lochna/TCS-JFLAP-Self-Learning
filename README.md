## About this repository

This repository collects work for the 35 JFLAP self-learning topics. Files with the `.jff` extension can be opened using JFLAP; PNG files show results of interactive activities. The date suffixes are the dates recorded in filenames.

## How to open the experiments

1. Download [JFLAP](https://www.jflap.org/).
2. Download the desired `.jff` file from this repository.
3. Open JFLAP, choose **File → Open**, and select the downloaded file.
4. For `.png` entries, open the image directly in GitHub.
